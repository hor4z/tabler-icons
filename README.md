# tabler-icons (fork de Rant)

Espejo de [tabler/tabler-icons](https://github.com/tabler/tabler-icons) para `@rant/icons`.

- `main`: copia exacta de Tabler, se sincroniza sola todos los días (`.github/workflows/sync.yml` en esta rama).
- `sync`: la rama por defecto, solo tiene el workflow. No se commitea nada en `main`.

Si a Rant le falta un icono, se busca acá en `main` (`icons/outline`, `icons/filled`). Ver `packages/icons/README.md` en el repo de Rant.
